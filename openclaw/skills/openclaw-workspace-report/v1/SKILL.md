# Workspace report

1. Run `ls` with the exec tool to list the workspace.
2. Read at most two files that look most useful, with the read tool.
3. Reply under the heading `## Workspace report`, with a table: `| File | What it is |`, one row per file from step 1.
   Keep each description to a few words.
4. After the table, one sentence on what the workspace seems to be for.

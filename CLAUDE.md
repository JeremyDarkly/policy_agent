# CLAUDE.md

## IdeaFactory pipeline

Any GitHub issue carrying an `idea`, `proposal` or `approved` label is governed by the files in `.claude/pipeline/`:

- [`proposal-guidelines.md`](.claude/pipeline/proposal-guidelines.md): how to write, spike and revise a proposal.
- [`proposal-template.md`](.claude/pipeline/proposal-template.md): the required structure of the proposal in the issue body.
- [`STATE.md`](.claude/pipeline/STATE.md): the label state machine, its guards, and who sets each label.

Read them before working on such an issue.
